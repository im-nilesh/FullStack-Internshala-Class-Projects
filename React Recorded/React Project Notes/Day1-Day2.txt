Day 1 - React Router + Project Setup

-   React Router enables navigation without page refresh.
-   createBrowserRouter() defines routes.
-   RouterProvider provides routing to the app.
-   Link is used instead of anchor tags.
-   Dynamic routes use parameters like /product/:id.
-   Layout component holds shared UI.
-   Outlet renders child routes.
-   Nested routes avoid repeating layouts.
-   Props flow from Parent → Child only.
-   Sibling components cannot directly pass props.
-   Prop drilling occurs when props are forwarded through many levels.
