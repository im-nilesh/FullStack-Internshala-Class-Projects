Inline Css :
    Styling defined inside the tag.
Internal Css:
    Styling defined inside the html file.
Extrenal Css:
    Styling defined inside a seperate css file.

---------------------------------------------------------

Every HTML is considered as a part of box model.

#properties 4:
padding : area beyween content and border
margin : area between two boxes
border : border of the entire box
content (width & height) : where the main content lies

content border and padding will occupy the element area.

box model properties do not work with the inline elements
you need to convert inline elements into block elements.
