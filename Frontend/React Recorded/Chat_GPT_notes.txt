1. INTRODUCTION TO REACT
========================

What is React?
--------------
React is a JavaScript library used to build user interfaces (UI).
It was developed by Meta.

React is mainly used for:
- Single Page Applications (SPA)
- Dynamic websites
- Reusable UI development
- Fast rendering applications

Why React is Popular
--------------------

1. Component-Based Architecture
React breaks UI into reusable components.

Example:
--------
function Navbar() {
  return <h1>Navbar</h1>;
}

Benefits:
- Reusable
- Maintainable
- Cleaner code
- Easier debugging

2. Virtual DOM
---------------
React does not directly manipulate the Real DOM every time.

Instead:
1. Creates Virtual DOM copy
2. Compares old and new Virtual DOM
3. Updates only changed parts

This process is called:
- Diffing
- Reconciliation

Why important?
---------------
Real DOM updates are expensive.
React minimizes unnecessary updates.

3. Fast Performance
-------------------
Because React updates only changed elements.

4. Reusability
--------------
Write once and reuse many times.

5. Huge Ecosystem
-----------------
Libraries:
- React Router
- Redux
- Axios
- Material UI

4. JSX
======

Definition
----------
JSX means JavaScript XML.

Allows HTML inside JavaScript.

Example:
---------
const element = <h1>Hello</h1>;

How JSX Works
-------------
JSX gets converted into:
React.createElement()

Example:
---------
<h1>Hello</h1>

becomes:

React.createElement("h1", null, "Hello")

Rules of JSX
------------

1. Single Parent Element

Wrong:
------
return (
  <h1>Hello</h1>
  <p>World</p>
)

Correct:
--------
return (
  <div>
    <h1>Hello</h1>
    <p>World</p>
  </div>
)

2. class becomes className

<div className="box"></div>

3. JavaScript inside {}

const name = "Nilesh";

<h1>{name}</h1>

4. Self Closing Tags

<img src="img.jpg" />

7. STATE
=========

Definition
----------
State stores dynamic data.

When state changes:
- Component re-renders

useState Hook
--------------

const [count, setCount] = useState(0);

Explanation:
------------
count -> current value
setCount -> update function
0 -> initial value

Example:
--------

import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h1>{count}</h1>

      <button onClick={() => setCount(count + 1)}>
        Increment
      </button>
    </div>
  );
}

Important Interview Concept
---------------------------

State updates are asynchronous.

Wrong:
------
setCount(count + 1);
console.log(count);

Correct:
--------
useEffect(() => {
  console.log(count);
}, [count]);

====================================================

8. BATCHING
===========

Definition
----------
React groups multiple state updates together.

Example:
--------

setCount(count + 1);
setCount(count + 1);

Result may not become +2.

Correct:
--------

setCount((prev) => prev + 1);
setCount((prev) => prev + 1);

Why?
----
Because React batches updates.

12. useEffect
==============

Definition
----------
Handles side effects.

Examples:
- API calls
- Timers
- Event listeners

Syntax
------

useEffect(() => {

}, [])

Runs Once
---------

useEffect(() => {
  console.log("Mounted");
}, [])

Runs Every Render
-----------------

useEffect(() => {
  console.log("Rendered");
})

Runs on Dependency Change
-------------------------

useEffect(() => {
  console.log("Changed");
}, [count])

Cleanup Function
----------------

useEffect(() => {

  const interval = setInterval(() => {
    console.log("Running");
  }, 1000);

  return () => {
    clearInterval(interval);
  };

}, []);

Why cleanup important?
----------------------
- Prevent memory leaks
- Remove listeners
- Clear intervals
