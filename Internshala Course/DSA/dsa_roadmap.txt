====================================================

2. TIME COMPLEXITY
==================

Definition
----------
Measures how fast an algorithm runs.

Big O Notation
--------------

O(1)     Constant
O(log n) Logarithmic
O(n)     Linear
O(n log n)
O(n²)
O(2^n)

Examples
--------

O(1):
Array access

O(n):
Linear search

O(log n):
Binary search
