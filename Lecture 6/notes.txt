GRID :

2D In nature and responsive

In Grid unlike the flex we can define the rows and columns styling.

By default the gird works in row, but because it is 2D we talk about the area, if we initially dont have any parameter, it will go into vertical display

To see grid working we need to define rows and column 

we use grid-template-columns to define number of columns that we need
for ex : grid-template-columns 100px 100px 100px (column will always have width).
         grid-template-rows 100px 100px 100px (3 rows making heights)

         we have gird-flow here just as flex direction.

         when we dont define the rows, they are automaticallly managed, we can use grid-auto-rows property to give the height for the rows that are automatically managed.

we can use the child property such as 

grid-row-start
grid-row-end
grid-column-start
grid-column-end

use the lines that samarth said in the class

we can make the rows/columns expand into other rows/columns using the above properties.

we need to mention the LINE that the row/columns start and end in order to make them expand.

we can use grid template area to:
    when we give grid-area: name

    we can define like 

    grid-template-areas : "header header header"
                          "nav1 main nav3"
                          "nav2 main nav3"
                          "footer footer footer"
