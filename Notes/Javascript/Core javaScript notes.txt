Execution Context

in js there the memory exection is generaaly done in followiing step:

initially there is a global memoery allocation for all the variables that are defined in the program,
once the memory allocation is done the code execution starts and the variables recieve valuesfor those that
memory allocated

Whenever we are invoking any function, within the execution context therre is another exection context created,
that would be the local execution context for that function,
within this exection context there would be same 2 phases i.e 
Memory allocation phase and the other would be code exection phase.


There is a call stack present that has Global execution context at the end,
then the local execution context that are being called because of the functions get stacked up on the GEC 
once these local exection context are done with the memory allocation and the code execution they are popped off of the stack 
and at the end the GEC is executed.

Hoisting

We can access a variable in Js even before declaring the variable, this is known as hoisting.

for example:
    console.log(a);
    var a = 9;
    console.log(a);

    output for this block of code will be :
    undefined
    9

This is going to happen because during the execution context phase the memory is already been assigned to the variable about
in the program the value was not yet been declared for that variable and because of that we get undefined,
but later on we have provided a value of 9 that is why the output further shows us 9.

The above example was for variable hoisting,
the same can be applied for function hoisting too.

Reduce Method : 

when we want to reduce the array and get a single output then we use reduce method

reduce function works a bit differently
suppose we want to add all the elements of the array

const arr = [1,2,3,4,5]
const updatedArr = arr.reduce(function(acc,curr){
    acc = acc + curr
    return acc
},0)

the acc is basically the final collected value this array is going to return, 
the curr is the value that is going to iterate

the above function will give the sum of all numbers and the 0 is basically the initial value of the acc variable

to find max element of array using reduce method

const arr = [1,2,3,4,5]
arr.reduce(function(max, curr){
    if(curr>max){
        max = curr
    }
    return max
}, 0)

function to calc square of the numbers

function sumOfSquares(arr) {
	return arr.reduce((acc, cur) => acc + cur * cur,0)
}
console.log(sumOfSquares([1, 2, 3, 4]));
