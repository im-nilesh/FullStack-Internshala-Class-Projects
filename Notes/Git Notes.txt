git clone : for cloning the code from github (remote) to local machine (git).

git status : gives the status of the repo.

git push origin main cmd for pushing to the main branch

git checkout -b "feature1" : This cmd creates a new branch called as feature1.

git branch: cmd is used to know the number of branches active in the repo.

git checkout main: allows us to move the the main branch, we can just give the name of the branch that we want to go to.

To push the code in feature1 branch, we use git push origin feature1

to get the changes on the local machine we use, git pull origin main, 
    this cmd pulls the changes from the github to the local machine

git merge branchname, it merges the branchname into the current branch that we are on.

we need to resolve the merge conflicts manually, if they appear in the code.

we can use git reset filename, if  we dont want to commit the changes. (remove after adding but  before commiting)

we can use git reset HEAD~1, to remove the most  recent change after commiting. (remove the first  file after commiting but before pushing)

if we want to remove multiple changes, we can use git reset id, this cmd will remove all the commits that are done upto the id that is entered.
