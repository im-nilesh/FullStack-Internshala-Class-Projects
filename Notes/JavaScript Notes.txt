Variables

We can declare variables in Js directly, but using var, by using let(recommended) and by using const.

use var to declare variables for older browsers, 

const is a type of variable whose values cannot be changed.

example: 
let a = 15;
console.log(a);

Js identifiers are same as python, cannot give numbers,
can give underscore, no special charcater at the front.

DATATYPES:

Null (let x = null;)

undefined (let age; or let age = undefined;)

BigInt (let x = BigInt(216516513216354321321);)
