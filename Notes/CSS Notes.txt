CSS POSITIONING

There are 5 ways in which we can position an element

1. Static : No change, the element is present where it was situated before.

2. Absolute : We can set the position attribute as position : absolute left :300px the element will move 300 px from the left

3. Relative : The element will lose it original space and other elements will take the space of the element that was present before
 the element was move, It will moves towards its closets realtive ancestor. 

4. Sticky : The element remains to be sticked even while scrolling. It scrolls but stops once the value that is given to it is reached.

5. Fixed : The element is fixed at a place, even after scrolling it reamins to be fixed

FLEX 

1. Flex is basically a easier way to do things which i was doing in the wrong way, trying to alaign everything as i was giving padding etc,
If i use FLEX property on the parent class, the elements inside the parent become flex elements and
they show up in a row in a grid type manner

2. Flex Wrap element is basically used to Wrap the flex items in order  to control the overflow of these items.

3. Flex Grow property is used to occupy the extra spacing that is left out if the width and height of a flex item is previously fixed

for Example: flex-grow : 1

4. Flex Shrink property is used to adjust the screen size, i.e if there is a flex element greater than that of the screen size the flex shrink will shrink the item in 
order to get the optimal screen size and the layout doesnt get broken.

5. Flex Basis is used to set the initial width of the flex element.

6. Flex is short hand property for flex grow, flex shrink and flex basis, 
It takes 3 value i.e flex grow, flex shrink, flex basis at the end.

7. Justify content acts on the main axis of the flex container, it allows us to put the content at end center or start based on a row or a column.

8. Space Around = x space in between and x\2 at the start and end.
   Space Between = start and end has no space and all the space is divided between
   Space Evenly = Evenly Spaces everything.
   Align Items works on the cross axis.
